The short version
Everything stays on this phone. SpendWise has no account, no server and no analytics. It cannot send your spending anywhere because there is nowhere for it to be sent.

What is stored

Your transactions — amount, merchant, category, date, and the bank message a transaction came from. In a SQLite file in this app's private storage, which other apps on the phone cannot read.
What you have corrected — when you recategorise a merchant, that correction is stored so the next one is right. It is used only to categorise your own transactions.
Sender reputations — which sender IDs your bank actually uses, learned from the messages you have received, so a lookalike can be spotted.
Your settings — currency, theme, thresholds.

What is never done

✗ No network requests carrying your data. The app runs a small server on the phone itself and talks only to that.
✗ No analytics, no crash reporting, no advertising identifiers, no third-party SDKs.
✗ No account, no email address, no phone number.
✗ Nothing is read from messages that are not from a bank or UPI sender — personal messages and OTPs are ignored.

Your copy of everything

Because there is no cloud copy, keeping a backup is on you — and it should be, but the app has to make it easy.
Download a full backup Export transactions as CSV

Deleting your data

Uninstalling SpendWise deletes the database with it. There is no copy anywhere else, so an uninstall is permanent — take a backup first if you want to keep the history.
To clear only what SMS capture picked up, use Clear unreviewed captures in Settings.
