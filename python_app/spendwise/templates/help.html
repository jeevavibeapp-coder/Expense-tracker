“Couldn't start SpendWise”

The app runs a small Python engine on the phone and waits for it to answer before showing anything. This screen means it did not answer in time.

On the first launch that engine has a lot to do: unpack Python, load the app, and build the database. On a slower phone that can take a while, so tapping Retry once is worth doing before anything else — the second launch is much faster because the work is already done.

If it keeps failing, the grey box on that screen carries the actual error. That line is what identifies the problem; a screenshot of it is more useful than any description.

Android refused to install the app

Two different refusals, with two different causes.

“App blocked to protect your device” (Play Protect), or INSTALL_FAILED_VERIFICATION_FAILURE. SpendWise asks to read bank SMS, and Play Protect blocks any app that requests SMS access unless it came from the Play Store. It is not reacting to anything found in the app — it is reacting to the permission being requested at all.

  1. Play Store → your profile picture → Play Protect
  2. The gear icon → turn off Scan apps with Play Protect
  3. Install SpendWise
  4. Turn it back on. It protects you from everything else.

On Xiaomi, Redmi and POCO there is a second gate: Settings → Privacy protection → Special permissions → Install unknown apps, and if it still refuses, turn off MIUI optimization in Developer options.

From a computer, adb install app-release.apk avoids the prompt entirely.

In India, Singapore, Thailand and Brazil this is Google's enhanced fraud protection, which refuses any sideloaded app declaring SMS, notification-listener or accessibility permissions — usually with no “install anyway”. Turning Play Protect off does not always help there.

Two things that do work:

  1. adb install from a computer. The ADB route is not subject to this check.
  2. Install the no-SMS build. It never asks for the permission, so there is nothing to block. You add transactions yourself or paste bank messages into Import.

Apps like this one on the Play Store are not built differently — they arrive by a route that is not scanned.

INSTALL_PARSE_FAILED_NO_CERTIFICATES is a different thing: that APK was never signed and no setting will let it install. Use a signed build.

My transactions are not being captured

SpendWise scans the inbox for bank and UPI messages each time it opens, and listens for new ones while it runs.

If nothing is being captured, in order of likelihood:

  1. SMS permission is off. Settings → SMS auto-capture will say so, with a button to turn it back on.
  2. Your phone is killing the app in the background. On Xiaomi, Redmi and POCO, Oppo, Vivo and Realme this is the usual cause. Enable Autostart for SpendWise in your phone's Settings → Apps, and set its battery mode to No restrictions.
  3. Your bank's message format is not recognised yet. Settings shows a count of messages that looked financial but could not be read; you can export them from there to see what was missed.
A message was held instead of being added

That happens when the sender is not one your bank has used before, or the message has the shape of a scam — a payment link, an urgent deadline, a request to call a number.

Held messages are never deleted and never added on their own. Open Alerts → Held messages to see each one with the reason, the original text, and buttons to add it, discard it, or block the sender for good.

A transaction got the wrong category

Tap the transaction and change it. That correction is remembered for that merchant, and the next one arrives already correct.

How eager the app is to categorise without asking is yours to set: Settings → Smart engine has the two confidence thresholds. Raise auto-save to be asked more often; lower it to be asked less.

The same purchase appears twice

Some banks send both an SMS and a UPI confirmation for one payment. SpendWise removes exact duplicates automatically, but a pair that differs in wording or timing can slip through.

Swipe the row left, or open it and delete it. Deletes are soft — an undo bar appears, and nothing is really gone until the app is reinstalled.

I am getting a new phone

Nothing is stored anywhere except this phone, so a copy has to be made deliberately.

  1. Settings → Download a full backup. Save the file somewhere off the phone.
  2. Install SpendWise on the new phone.
  3. Settings → Restore from a backup and pick that file.

The CSV export is a report for a spreadsheet, not a backup — it cannot rebuild your merchants, budgets or learned categories.

The numbers do not look right

Two corrections are applied automatically and explain most surprises:

  • A transfer between your own accounts is not spending, so a matching debit and credit within a few minutes is excluded from totals.
  • A refund reduces the original spending instead of counting as income.

If a total still looks wrong, Activity → search for the merchant is the fastest way to find what is behind it.

Does this work without internet?

Yes, always — that is the whole design. There is no server to reach, so aeroplane mode changes nothing about how the app behaves.

Still stuck?
Nothing is sent from this app automatically. If you want to report a message your bank sends that SpendWise cannot read, exporting it is an explicit action you take, and the file stays on your phone until you choose to share it.
