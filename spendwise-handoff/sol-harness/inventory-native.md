## Scope caution

This is an independently assembled feature inventory, not evidence that M3 parity is complete. Some core helpers are not standalone UI features: for example `C/Prompts.kt` has a single-capture prompt model, but the native Activity uses the grouped Review page rather than exposing that prompt. Likewise detector output alone is not a recurring-management screen, a transfer editor or a fraud push notification. Existing parser, dedup, timestamp, contrast and document-I/O findings remain qualifications on otherwise present features.
